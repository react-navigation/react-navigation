# AI Usage Policy

We welcome the use of AI as a tool to assist with development. Contributions made with AI assistance must follow these guidelines:

1. **AI usage must be disclosed**: You must state the tool you used (e.g. Claude Code, Codex, Cursor, Amp etc.) along with the extent that the work was AI-assisted for any code changes you contribute.
2. **The human author must understand all the code**: You should be able to explain and justify all code changes made, and how they integrate with the existing codebase. If you don't understand the changes, consider opening an issue instead of submitting a pull request.
3. **All text must be written by a human**: You can use AI to assist with drafting, reviewing, translating or improving grammar and clarity, but you must write issue and pull request descriptions, responses, comments, and documentation in your own words.

This project is maintained by humans, and we want to ensure a high standard of quality. Every discussion, issue, and pull request is read and reviewed by humans, so we only ask that we are interacting with other humans.

AI written content is often verbose, repetitive, and full of unnecessary details. So they put burden on the human reviewers to sift through and find the relevant information. We appreciate it if you took the time to write them yourself to make the review process easier.

Contributions that do not follow this policy will be closed. Repeated violations may result in being blocked from contributing to the project.
